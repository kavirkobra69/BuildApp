# KavirDL

Android downloader for YouTube, Instagram, TikTok, Spotify tracks and Pinterest images, GIFs and videos.

- Save button copies the file into the gallery (Movies, Music or Pictures under KavirDL)
- Settings has a built-in V2Ray config (vless, vmess, trojan or JSON); Xray runs inside the app and only the app's own traffic uses it, no VPN
- Share a link from any app to KavirDL to fill the link field

## Build

Actions tab, workflow "Build APK". The APK is attached to the run and to the release named latest.
